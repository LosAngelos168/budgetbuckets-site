# budgetbuckets-site

The public GitHub Pages site for the BudgetBuckets iPhone app — the privacy
policy and support pages its App Store listing links to. The app itself
lives in a separate private repository.

Served at `https://losangelos168.github.io/budgetbuckets-site/` via GitHub
Pages (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).

This repo's **Issues** tab is the app's public support channel — both pages
link to it.
